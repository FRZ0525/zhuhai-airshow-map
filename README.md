# 杭州 → 珠海航展 行程地图（2026）

交互式 Leaflet 行程地图，交互方式对齐青岛旅游规划地图：左侧/底部面板 + 天数筛选 + 地图标点 + 高德/百度导航。

## 怎么打开

1. 解压 `珠海航展行程地图.zip`
2. 进入文件夹后用浏览器打开 **`index.html`**
3. 图片在 `assets/photos/`，请保持相对路径，不要只拷贝单个 html

本地 `file://` 打开时默认用 Esri 底图；有网络时也可切换 OpenStreetMap。

## 行程摘要

- 2 成人，杭州出发（飞机，不自驾）
- **12/12**：HGH→CAN（参考 MU5211）→ 广州南 → 广珠城际 → 珠海住一晚（珠海站 > 长隆 > 横琴 > 金湾）
- **12/13**：珠机城际 → 珠海机场站 3 号口 → 步行约 300 m → 航展中心；约 16:00 离场，晚回广州
- **12/14**：广州→杭州（班次待选）
- 门票：大麦，¥600 / ¥1000；公众日买 12/13

## 重建

```bash
python3 build.py
python3 inline.py page_raw.html index.html
```

坐标来自 OpenStreetMap Nominatim；航展大门等近似点已在数据里标注。官方 2026 Site Plan PDF 构建时未能下载。
